# Catalog content policy

Listings are open data (CC0). Kestrel Labs reviews and merges pull requests. Being listed is not a warranty of the software.

**Accepts:** FOSS desktop and container apps people can run on Linux; AppImage, Flatpak, and optional distro packages.

**Prohibits:** adult content, malware, license-violating apps, and anything that impersonates another publisher.

Age-rating fields belong in listing metadata when known (`age_rating` on the listing: `everyone`, `everyone-10`, `teen`, `mature`, `adult`).

`verified: true` is set only by Kestrel Labs after publisher verification. Community pull requests must not set it.
