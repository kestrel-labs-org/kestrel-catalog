# Kestrel Catalog

Community-maintained **app listings** for [Kestrel App Manager](https://github.com/kestrel-labs-org/kestrel-app-manager) on **Linux** (Debian-based distros and variants first).

Listing metadata in this repository is dedicated to the public domain under **[CC0-1.0](./LICENSE)**.

## How to contribute

1. Read the [listing schema](./docs/SCHEMA.md).
2. Add or update a YAML file under `listings/`.
3. Open a pull request (the template includes the CC0 dedication).

A validation check will lint listing files once CI is enabled on this repo.

## Layout

```
listings/     # one YAML file per app (see schema)
docs/         # schema and contributor notes
```
