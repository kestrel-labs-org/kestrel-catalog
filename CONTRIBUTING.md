# Contributing to the Kestrel Catalog

This repository holds **listing metadata** (YAML), not application source.

- Schema: [docs/SCHEMA.md](./docs/SCHEMA.md)
- License: listing metadata is **CC0-1.0** (public domain dedication)
- By opening a PR that adds or changes listings, you dedicate that metadata to the public domain under CC0-1.0 (see the PR template)

No CLA or DCO is required for this repo.
